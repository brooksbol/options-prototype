# Wheelwright Coming Soon (User-Facing)

> **Status:** Canonical Project / Operational State (Category C).
> **Authority:** This file is the single source of truth for capabilities Wheelwright is willing to communicate to users as "coming."
> **Method:** Deliberately curated from authoritative/reconciled product intent. Never auto-populated.

## Semantics

This answers **"what future product capabilities are we willing to communicate to users?"**

It is distinct from the Priority stack. An item must **not** appear here merely because it is high priority, exists in the parking lot, appears in the LVT, or has an ADR. Inclusion is an explicit, curated product-communication decision.

## Governing rules

1. Entries are **curated by explicit Principal decision only**. Presence anywhere else in the repository is not sufficient cause for inclusion.
2. Avoid false precision: **no invented delivery dates**, no committed timelines. An optional coarse, honest status word (e.g. `Exploring`, `Planned`) may be used only when it reflects reconciled intent.
3. Keep entries user-facing in language: a short capability name and a one-line description a user would understand.
4. If nothing is currently approved for user communication, this file states that honestly and the surface shows nothing rather than inventing items.
