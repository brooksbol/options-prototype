# Runtime invariant register

These are candidate contract obligations, not implemented application behavior. JSON Schema enforces local shape, discriminants, explicit units, status/null rules and basic bounds. It cannot prove source truth, permission grants or sums over separate resources. The offline oracles in `verify.py` check finite falsifiers only.

## Final targeted corrections

- The schema rejects CLOSED with unresolved/non-scoped closure evidence, but cannot compare a linked Construction's exposure or prove actual closure. CLOSED terminal transition/new-GUID rules remain runtime obligations.
- Exact bound Model-version URI syntax is schema-enforced in Recognition, nested composition and Model roles; resolution/immutability and applicability remain runtime proof.
- Broker reservation record **type** is required structurally for established broker encumbrance/reservation. Its predicate, scope, currency, timing and actual broker guarantee must be verified; a label or pointer alone is insufficient.
- Snapshot catalog is authorized by token User and Account holdings capability. Scope applies to discovery, selection, evidence and continuation; a cross-Account selected ID is404 without a global lookup. Source hash/recorded time are retained-source metadata, not a broker event clock. Source/artifact targets still require their own grants.
- openedAt, originalDays, openingEvidence and any dependent lifecycle/summary timestamp require their actual source capability. Redacting an Order link alone does not permit an opening clock to survive. Remaining DTE from authorized contract expiry is independently displayable. A separately admitted Position fact may have separate authority; no automatic promotion is assumed.
- predecessor is the immediate preceding retained Construction instance when known. Schema checks URI/null/status shape, not chronology or whether intermediate instances were omitted. UNKNOWN+null+warning is permitted; never replace missing immediate history with an original shortcut. Explicit synthetic intermediate snapshots prove example navigation only, not full broker continuity.
- Raw custody quantities remain known during a coverage conflict; coverage-dependent names, geometry and summaries must qualify that conflict in every affected Position. Aggregate owned inventory and aggregate eligible coverage are separate invariants. No tax-lot or share-to-call association workflow.
