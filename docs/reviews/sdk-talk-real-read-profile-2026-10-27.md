Quote MCP uses the existing3100 held-read backend and its existing credential/permission boundary; Account grants are not repurposed as quote authority.

Actual real Position page verification establishes five items and continuation, not whole-Account completeness.

The real profile uses ordinary local multi-turn sessions; the older restricted metadata profile still uses fresh sessions and remains separately labeled. - Loopback Host allowlist accepts exact `localhost:<port>` and `127.0.0.1:<port>`; arbitrary Host is rejected. POST still requires matching Origin and per-preview CSRF token. No general Host/Origin bypass.
