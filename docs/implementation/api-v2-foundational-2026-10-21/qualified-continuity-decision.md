# Qualified inventory continuity — implementation decision record

Principal instruction in this implementation session, October21,2026; bounded evidence-reconciliation correction, not a universal split/recombine policy.

Repeated observations are not new economic events. Reuse an independently generated existing UNRESOLVED Position GUID only when exactly one candidate has compatible Account, source inventory identity, contractual terms and applicable quantity. Keep occurrence continuity UNRESOLVED. Do not infer opening date, uninterrupted holding period, original cost basis, opening transaction or verified roll history. A close/reopen between identical observations may remain undetectable.

Never resurrect CLOSED, merge ambiguous candidates, infer a closure from missing holdings, invent split/recombine relationships, assign particular shares to calls or add operator-association tooling. Preserve independent retained holdings and warn when occurrence continuity is unknown. Complete scoped closure remains terminal; later observed exposure after that closure receives a new GUID with its own actual evidence qualification.

Initial inventory can be represented by an UNRESOLVED Position; a conflicting/ambiguous existing active scope must not produce duplicate guesses. Retained historical observations must not roll current custody backwards. Tests must distinguish actual immutable resource semantics from the absence of broker event proof.

The Principal subsequently instructed continuation with engineering judgment for further routine choices and reporting of unresolved matters. No permission for trading, deployment, push/merge, wwlive or Product acceptance was added.
