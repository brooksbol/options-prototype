# Tradier market-data capability sheet

**Date:** October 5, 2026

**Status:** Category E one-page provider reference for the `PL-CLI-01` Product decision and `PL-API-03` reconciliation. Product semantics live in `docs/parking-lot-10.md`; the investigation snapshot is `docs/76-ww-fetch-api-v2-investigation-snapshot-2026-10-05.md`. This sheet authorizes no provider, CLI, API, or persistence change.

Provider-native, Wheelwright-evidence, and client-capability units need not coincide. Links are current official Tradier docs; the last column is current Wheelwright behavior.

| Data | One provider call gives us | Batch? | Wheelwright now |
|---|---|---|---|
| [Underlying quote](https://docs.tradier.com/reference/brokerage-api-markets-get-quotes) | One or more named security quotes: last/close, bid/ask and sizes/dates, volume, trade date, prior close, description/type and other [documented fields](https://docs.tradier.com/docs/quotes), as supplied | **Yes**: comma-separated symbols in GET; [POST](https://docs.tradier.com/reference/brokerage-api-markets-post-quotes) for larger lists | Chain adapter retains price, name, previous close in a normalized chain; no independent durable quote observation. A separate index-glance path reads quotes without persisting them. |
| [Option-contract quote](https://docs.tradier.com/docs/quotes) | Quote for an explicitly named OCC contract, with option fields such as strike, expiry, OI and available Greeks/IV | **Yes**: option symbols use the quotes operation's multi-symbol input | No independent contract-quote acquisition/persistence; contracts are retained inside chains. |
| [Expirations](https://docs.tradier.com/reference/brokerage-api-markets-get-options-expirations) | Listed expiration dates for one underlying; optional strikes, contract size or expiration type | **No documented multi-underlying request** | Persists expiration evidence; backend derives DTE and selects eligible/primary dates. |
| [Chain](https://docs.tradier.com/reference/brokerage-api-markets-get-options-chains) | Many option contracts for **one underlying + one expiration**, with optional Greeks/IV | **No documented multi-underlying or multi-expiration request** | Persists one chain evidence row per `(symbol, expiration)`; currently adds an underlying quote during normalization. |
| [Time & sales](https://docs.tradier.com/reference/brokerage-api-markets-get-timesales) | Bars or ticks for one security and time range; tick responses can be very large | **No documented multi-symbol request** | Pacer-governed, short-cache read-through for market-context views; not durable spot history. |
| [Market clock](https://docs.tradier.com/reference/brokerage-api-markets-get-clock) | Current global intraday market state and times | **Global**, not per symbol | Wheelwright instead owns provider-aware session/admissibility classification; a provider clock is not that verdict. |
| [Market calendar](https://docs.tradier.com/reference/brokerage-api-markets-get-calendar) | Global trading-day calendar for a month | **Global**, not per symbol | Session policy currently uses Wheelwright's calendar conventions. |
| [Option-symbol lookup](https://docs.tradier.com/reference/brokerage-api-markets-get-lookup-options-symbols) | Contract identities, including additional roots, for one underlying | **No documented multi-underlying request** | No corresponding `ww fetch` evidence unit; lookup is discovery, not contract quotation. |

**Limits and partial responses.** Tradier documents `/markets` rate limiting at **120 production requests/minute per access token**, with request-oriented headers; it does not document a separate per-symbol weight for a multi-symbol quote. No numeric symbol maximum, URL/body-size maximum, or pagination rule was found for the operations above. A prior Wheelwright production probe returned all 14 specimen quotes in one GET; a mixed valid/invalid probe returned HTTP 200 with valid quotes plus `unmatched_symbols`. Thus an HTTP success must be reconciled against every requested subject. Tradier documents JSON single-object/array shape variation; no equivalent partial-chain behavior was established. [Rate limits](https://docs.tradier.com/docs/rate-limiting) · [Response format](https://docs.tradier.com/docs/response-format) · [Market data availability](https://docs.tradier.com/docs/market-data).

**First v2 semantic debt:** The current held-price read comes from the primary-chain row, while an underlying quote is not independently persisted. Before common-API design, reconcile quote observation identity, field-specific provider time versus receipt/commit time, provider/environment and fencing provenance, retained-old-value failure behavior, and coexistence or precedence between independent quotes and chain-embedded spot. ADR-015 already forbids treating chain acquisition time as independent quote age. No storage or HTTP form follows from this sheet.
