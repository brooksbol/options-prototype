WW-SHOW(1)                 Wheelwright                 WW-SHOW(1)

NAME
    ww-show - inspect and query canonical held direct-quote observations

SYNOPSIS
    ww show SUBJECT... [--quote] [OPTIONS]
    ww show --quotes [OPTIONS]
    ww show --fields
    ww show --help | -h | --man

SEMANTICS
    Read held complete canonical observations only. Never acquire, refresh,
    contact providers, evaluate reuse/freshness, repair evidence, or substitute
    legacy chain prices. Old, unenrolled, non-reusable and retained holdings
    remain readable. Strict full validation precedes filters and projections.
    Reported change is source evidence, not a recomputed return or a guaranteed
    regular-session "today". The held collection is not the market universe.

SELECTION AND PROJECTION
    --quotes
        Inspect every subject in the complete held inventory, symbol ascending.
        Conflicts with explicit subjects. Bare show remains usage error.
        ww ls quotes remains inventory/discovery; show inspects full facts.
    SUBJECT...
        Canonical identity (BRK/B, not a transport token). Uppercase, deduplicate
        by first occurrence and preserve input order. No acquisition limit.
    --quote
        Existing direct-quote facet; does not select subjects by itself.
    --only FIELD[,FIELD...]
        Exact named ordered projection, including repeats; never adds symbol
        or a sort/filter field. One argument. Conflicts with --all-fields,
        --verbose and --jsonl.
    --all-fields
        Every installed public field in registry order (currently 36), one
        observation per horizontal row. Missing fields remain represented.
        Conflicts with --only and --verbose; redundant with JSONL.
    --where FIELD=VALUE
        Repeatable exact-match filters, AND semantics. One argument, split at
        first '='; later equals signs are literal value text. Public field
        names only. Quote spaces/metacharacters for your shell. No fuzzy
        matching, expressions, OR, regex, ranges or missing/null sentinel.
        Text is exact case-sensitive public text: type=ETF, type=OTHER.
        Empty text matches a genuinely present empty string, never absence.
        Numeric literals use complete JSON-number grammar and exact decimal
        equality: 1, 1.0 and 1e0 are equal; no binary-number coercion.
        Instants require valid canonical UTC timestamp syntax and compare the
        exact instant including fractional precision. Calendar dates require
        valid YYYY-MM-DD. Missing fields never match. Invalid typed literals
        fail before credentials/HTTP. See each field's filter/sort type below.
        type=etf is valid text but does not match type=ETF.

ORDERING AND LIMIT
    --sort-by FIELD
        One public field; numeric exact decimal, text ordinal, instant
        chronological (full fraction), calendar date calendar ordering.
        Ascending default; sorting does not add the key to --only output.
    --absolute
        Numeric sort only; requires --sort-by. Compare magnitude, preserve the
        signed stored/displayed value. No derived public field is created.
    --descending
        Requires --sort-by; reverse primary ordering only. Missing stays last.
    --limit N
        Positive decimal integer, digits only (leading zeros permitted).
        Applied after full inspection -> filter -> sort, then projection and
        presentation. Limits output, never silently limits reads. Invalid N
        fails before credentials/HTTP. Without sort, retain selected order.
    Ties preserve selected-subject order. Missing sort keys stay last in both
    directions. Filters and sort keys use canonical values before rounding.

PRESENTATION
    --table | --tsv | --jsonl
        Explicit formats are mutually exclusive. Repeating the same format
        or boolean option is harmless. No explicit format: human on terminal,
        canonical headerless TSV when piped/redirected. --table forces human
        horizontal tables even through a pipe. --tsv forces machine output
        even on a terminal. --jsonl is complete public nested observations.
    -v, --verbose
        Preserve existing complete, subject-labelled FIELD/VALUE human tables
        with full values and uncut identifiers/clocks. Complete TSV/JSONL in
        machine formats. Conflicts with --only, --all-fields and --table.
    Ordinary human columns: SYMBOL TYPE LAST CHANGE % BID ASK RECEIVED PROVIDER
    ENVIRONMENT. CHANGE % is reportedChangePercent, in percentage points.
    Both reportedChange fields have + for positive, - for negative, zero 0;
    percentages append % without multiplying canonical values by 100.
    Human prices/changes use at most two fractional digits normally, trimming
    trailing zeros; sub-cent values retain at least three significant digits.
    Extreme magnitudes use compact scientific notation, never apparent zero
    for nonzero evidence. Counts are exact integers. No currency/lot unit is
    inferred. Verbose preserves exact numeric spelling with change signs/%.
    Human instants use local timezone (including TZ): compact ordinary clocks;
    complete horizontal tables add year/date/seconds/offset; verbose retains
    available fractions. regularSessionDate is never timezone-shifted.
    Tables have headers, aligned expandable columns, no clipping or omitted
    fields. All-fields is intentionally wide; use a horizontal pager.
    Missing human cells are '-'. Empty human results are explicit messages.
    All-failure invocations have diagnostics and no successful table/header.

COLOR AND TERMINAL COMPOSITION
    Only reportedChange and reportedChangePercent are green when positive,
    red when negative. Zero/missing and all non-change fields use default
    foreground. ANSI green/red (32/31), restore default foreground (39).
    Widths/padding are calculated before decoration. Human --table keeps color
    in pipes, following tt live's presentation-based convention. Nonempty
    NO_COLOR or TERM=dumb disables color, including --table; empty/unset
    NO_COLOR does not. No palette or FORCE_COLOR mode.
    TSV/JSONL and automatic machine redirection NEVER contain ANSI decoration.
    watch -c 'ww show SPY --table' interprets colors from watch's capture pipe.
    Use --table | less -SR for colors with horizontal scrolling (S = no wrap,
    R = render ANSI). Plain less -S need not render colors.

MACHINE REPRESENTATIONS
    TSV: same selected fields/order, one LF row per observation, no headers.
    Missing values are empty cells including trailing cells; present zero and
    empty string remain values. Controls/backslashes use documented escapes.
    JSONL: one complete public nested observation per success, optional facts
    omitted as contracted. Unknown backend/internal fields are not published.
    Canonical numeric source values and original timestamp strings stay exact;
    no human rounding, signs, percent decoration or placeholders enter either.

STREAMS, COMPLETION AND PERFORMANCE
    Ordinary explicit-subject show retains streaming successful stdout and
    independent stderr failures. Partial stdout with final exit 1 is intended.
    Collection/filter/sort/limit/all-fields/explicit-table queries buffer reads.
    Every selected subject is inspected before filter/sort/limit, including
    malformed observations a filter would exclude. Failures are identified on
    stderr, never alternate stdout records; exit 1 if any subject fails.
    Partial query diagnostics explicitly state ranking covers successful reads.
    Zero matches/empty holdings succeed: zero machine records, human message.
    One inventory GET plus one sequential instance GET per collection subject.
    No cross-subject snapshot, version pin, retry, provider fallback or silent
    cap. Sort is O(M log M); buffering O(M). Limit does not reduce HTTP work.
    Inventory failure is command-wide with no results. Capacity/output failure
    must be visible, never a truncated complete success. Clean EPIPE retains
    the existing convention; other output failures exit 1.
    Exit 0 complete success; 1 operational/subject/output failure; 2 usage/config.

ARGUMENTS, DISCOVERY AND SECURITY
    Options may precede/follow subjects; -- ends option parsing. Validate the
    entire grammar before credentials/HTTP. --fields is subject-free local
    discovery, no credentials/client initialization/provider/evidence access.
    One registry governs names/types/projection/catalog/generated man semantics.
    Accepted public field changes keep these synchronized. Scripts remain the
    proving/composition layer for unaccepted derived analytics and joins.
    WW_BASE_URL defaults http://localhost:3100; HTTPS outside loopback.
    WW_API_TOKEN export or literal private .env; independent quote.read grant.
    Existing transport-only path codec: slash _2F, underscore _5F, caret _5E,
    exactly one decode. BRK/B and literal BRK_2FB remain distinct. No credentials
    or raw transport exceptions in diagnostics; request and evidence IDs differ.

EXAMPLES
    ww show SPY QQQ
    ww show SPY --only symbol,bid,ask
    ww show SPY --all-fields --table | less -SR
    ww show --quotes --where type=ETF --sort-by reportedChangePercent \
        --absolute --descending --limit 10 --all-fields --table
    ww show --quotes --where type=ETF --sort-by reportedChangePercent \
        --absolute --descending --limit 10 --jsonl
    ww show --quotes --where regularSessionDate=2026-10-05 --all-fields --tsv
    ww show --fields
