NAME
    ww-show - inspect canonical held direct-quote observations

SYNOPSIS
    ww show SUBJECT... [--quote] [-v | --verbose] [--jsonl]
    ww show SUBJECT... --only FIELD[,FIELD...]
    ww show --fields
    ww show --help | -h | --man

SEMANTICS
    Bare subject and --quote inspect the same held direct quote in this slice.
    No acquisition, refresh, provider contact, reuse-eligibility evaluation,
    legacy chain-derived price substitution or evidence mutation occurs.
    Old, unenrolled, currently non-reusable and retained prior holdings are
    readable if their complete canonical representation is valid.
    Absence is not an invalid market symbol. Malformed held evidence fails in
    full even if --only excludes its malformed field. No repair is attempted.

SUBJECTS AND OPTIONS
    Input is canonical identity, such as BRK/B, never a transport token.
    Normalize uppercase, deduplicate by first occurrence and preserve input
    order. At least one subject for inspection; no inherited 30-subject cap.
    Boolean options and the one comma-separated --only argument may occur
    before or after subjects. -- ends option parsing. --only cannot combine
    with --verbose or --jsonl. Unknown/empty/invalid fields and subjects fail
    before credentials or HTTP. --fields is a separate subject-free invocation.

STREAMS AND COMPLETION
    Terminal default columns: SYMBOL TYPE LAST CHANGE BID ASK RECEIVED PROVIDER
    ENVIRONMENT. CHANGE is reportedChangePercent in percentage points.
    Human instants use local timezone (including TZ). Missing cells are '-'.
    --verbose uses identified subject FIELD/VALUE tables without clipping.
    Redirected output is headerless TSV in selected order; absent values leave
    empty cells including trailing cells. Controls/backslashes are escaped.
    --only selects exactly its named ordered columns, never adding symbol.
    JSONL emits one complete public nested observation per successful subject;
    unknown additive/internal backend fields are not published incidentally.
    Canonical numbers and timestamp strings remain machine values. No null,
    empty string or zero is fabricated for an absent field.
    Failures are independent stderr diagnostics, not stdout failure records.
    Success rows may already have been consumed before later failure: partial
    stdout under exit 1 is intentional. All distinct requested subjects must
    be accounted for. Exit 0 is complete success; 1 operational/subject/output
    failure; 2 usage/configuration. Clean EPIPE retains existing convention.

DISCOVERY AND DOCUMENTATION
    --help explains invocation. --fields is the installed name/description
    catalog (table on terminal, headerless TSV when redirected), without any
    credentials, HTTP, evidence or provider. This manual explains semantics.
    The same authoritative registry drives projection validation/rendering,
    runtime discovery and this generated semantic field reference. Accepted
    public field changes update all three together. Experimental script values
    are not automatically public show fields; Product acceptance is required.

SECURITY AND HTTP
    WW_BASE_URL defaults to http://localhost:3100; HTTPS required outside
    loopback. WW_API_TOKEN is exported or read literally from private .env.
    quote.read is independent of acquisition grants. One sequential bodyless
    GET per distinct subject, no redirect, retry, acquisition or fallback.
    API instance path uses a transport-only reversible codec: slash _2F,
    underscore _5F, caret _5E; other accepted canonical characters unchanged.
    BRK/B and literal BRK_2FB remain distinct. API decoding occurs once.
    Observation/acquisition identity is distinct from request correlation.

EXAMPLES
    ww show SPY QQQ
    ww show --quote SPY --only symbol,bid,ask
    ww show SPY QQQ --only bid,ask
    cat symbols.txt | xargs ww show
    ww show --fields
    ww show SPY --jsonl
