NAME
    ww — inspect and acquire Wheelwright evidence with Unix commands

SYNOPSIS
    ww [--help | -h | --man]
    ww COMMAND [OPTIONS] [OPERANDS]

DESCRIPTION
    ww supplies small evidence capabilities to people, shell scripts, and
    agents. The shell composes commands with pipes, redirection, and &&.
    Held-quote reads are separate from explicit acquisition. Domain history
    reads may use bounded backend read-through with truthful status.

WORKING COMMANDS
    history [--account ACCOUNT] [--table | --tsv | --csv | --jsonl] [--verbose]
        Read Account-scoped transaction evidence; omitted Account composes
        authorized Account reads. tastytrade supports backend-policy read-through;
        Fidelity uses retained imported CSVs. Exact money and source lineage,
        separate freshness/coverage, no strategy/P&L/tax accounting.
        See ww history --help and ww history --man.

    pull [-v | --verbose] [--no-color]
        ww pull — Update WW with everything so I can start doing stuff.
        SYNC -> DISCOVER -> FETCH -> REPORT. Concise truthful source report;
        partial failure is nonzero. Normal workflow: ww pull && ww history.

    ls accounts [--table | --tsv | --jsonl] [--no-color]
        List accounts you can access, with their aliases, names, broker
        associations and immutable IDs. Start with 'ww ls accounts', then
        'ww sync account pts' or 'ww positions --account pts --verbose'.
        Terminal table; redirected headerless TSV; --jsonl emits one Account
        per line. --table preserves the table when redirected.
        Run 'ww ls accounts --help' for examples.

    sync [account ACCOUNT] [-v | --verbose] [--no-color]
        Omitted selector processes applicable authorized Accounts. Includes
        authorized history updates through backend policy; per-Account failures
        preserve retained evidence and independent work continues.
        tastytrade: backend-owned API holdings acquisition; requires explicit
        account.positions.acquire:ID. No brokerage credentials in this client.
        Position reads never contact a brokerage.
        Scan ~/Downloads, identify supported account-attributed Fidelity CSVs,
        compare SHA-256 with the backend inventory, and process unseen content
        sequentially oldest first. Stop on failure; retained failures retry
        without duplicate upload. No local manifest/database. SYNC COMPLETE
        means discovered content processed, not continuous brokerage history.
        See 'ww sync --help' and docs/cli/ww-account-evidence.md.

    positions [--account ACCOUNT] [--verbose | --jsonl | --table] [--no-color]
        Canonical Position command; ww show positions remains a fully functional
        compatibility alias with identical arguments, output and exit status.
        With no Account argument, read available backend-held snapshots across
        all authorized Accounts. --snapshot requires --account.
        Read backend-held Position snapshots with explicit evidence gaps.
        --verbose includes constituents, provenance and separate close/order
        sections; it requests terminal layout even when redirected. Default
        redirected output is one complete JSONL backend read representation.
        Friendly aliases resolve through backend Account discovery.
        Requires account.read:ID and account.positions.read:ID. See 'ww positions --help'.

    show SUBJECT... | --quotes [OPTIONS]
    show --fields
        Inspect canonical held quotes without acquisition. --quotes selects
        the full held inventory; --where FIELD=VALUE filters exactly (AND).
        --sort-by FIELD [--absolute] [--descending] with --limit N selects
        ranked rows, then orders retained rows by the canonical field.
        --absolute affects bounded selection, not signed output ordering.
        --all-fields selects every public field; --only is exact projection.
        --table | --tsv | --jsonl choose explicit output; automatic terminal
        human tables / redirected canonical TSV remain. --table preserves
        human change colors through watch -c; NO_COLOR disables colors.
        Strict full validation; partial query results identified, exit 1 on
        any failure. Requires quote.read except local --fields discovery.
        Run 'ww show --help', 'ww show --fields', or 'ww show --man'.

    ls quotes [--type TYPE]... [-v | --verbose] [--tsv] [--jsonl]
        Discover current canonical direct-quote holdings through provider-free
        API v2 GET. Requires quote.read. Terminal table; redirected headerless
        TSV; explicit --jsonl for discovery summaries. --tsv is an accepted
        no-op; it does not change terminal output or override --jsonl.
        --type selects EQUITY, ETF, INDEX or OTHER (exact uppercase). Repeat
        for OR selection; duplicates are harmless. Full response validation
        precedes client-side selection; the GET has no query parameters.
        Zero matches succeed; verbose counts selected rows.
        Bare ls is usage error.
        Run 'ww ls quotes --help' or 'ww ls quotes --man'.

    fetch [-q | --quiet | -v | --verbose] [--force] [--] SYMBOL...
    fetch [-q | --quiet | -v | --verbose] [--force]
        Acquire canonical direct quotes for explicit named subjects through
        API v2. Bare fetch uses backend-selected holdings underlyings UNION monitoring subjects;
        empty is a no-op, incomplete coverage fails. Explicit operands use one batch.
        Ordinary fetch may reuse backend-eligible evidence; --force requests an
        upstream acquisition attempt subject to backend authorization/policy.
        Exit 0 only when every subject is fulfilled. A retained prior quote
        does not turn failed acquisition into success. Outcomes distinguish
        NEWLY_ACQUIRED, REUSED, and failures. Normal terminal status goes to
        stderr; quiet suppresses normal status and verbose adds endpoint and
        request context. Fetch does not display prices on the terminal.
        Run 'ww fetch --help' or 'ww fetch --man' for the current contract.

    prices [--] SYMBOL...
        Read the underlying prices Wheelwright currently holds, including
        explicit absence and acquisition state. This never acquires evidence.
        Run 'ww prices --help' or 'ww prices --man' for evidence limits.

    sort --by FIELD [--descending] [--]
        Read ww price composition records from stdin and emit those same
        records ordered by numeric price or symbol. When sorting by price,
        missing prices sort last.
        Price order is ascending unless --descending is given.
        Run 'ww sort --help' or 'ww sort --man' for the bounded input format.

    observed-prices [--] SYMBOL...
        Compatibility spelling for prices. The same read and output behavior
        applies; new examples use prices.

COLOR CONVENTIONS
    New or changed human presentations follow the accepted tt live motif:
    bright white ordinary text, sparse semantic accents, and dark gray
    technical Account IDs. Account aliases are cyan; BROKER labels use
    Fidelity green and tastytrade red as brand identity, not status.
    Restore neutral foreground after accents and reset output attributes.
    Machine output stays ANSI-free; honor NO_COLOR and TERM=dumb.
    Account tables also support --no-color, including with --table in pipes.
    Future presentation changes must verify visible alignment, reset behavior,
    opt-outs, machine fidelity and masking, then obtain visual acceptance.
    Existing accepted command-specific palettes remain separately governed.
    Full mappings and the existing ww show exception are recorded under
    CONV-UX in docs/parking-lot-10.md (Standing color standard for future ww changes).

OUTPUT AND COMPOSITION
    Direct terminal output is human-oriented. When stdout is piped or
    redirected, prices and sort emit bounded JSON Lines price records;
    fetch emits bounded per-symbol result records after completed work. Fetch
    writes its concise human status to terminal stderr and leaves terminal
    stdout empty. This is not a universal ww wire-format commitment. Results
    go to stdout; status and diagnostics go to stderr. Neither progress nor
    decoration belongs in composition stdout.

    Fetch records contain the authoritative direct-quote observation:

        ww fetch SPY QQQ > quote-acquisition.jsonl

    ww prices remains an independent v1 read of chain-associated price evidence;
    it does not inspect the v2 direct quotes acquired by fetch. Use ww ls quotes
    for canonical direct-quote holdings; this lists discovery summaries only. Use ww show for complete held quotes.

EXIT STATUS
    0   Command succeeded under its documented contract.
    1   Backend, input-record, or evidence-operation failure.
    2   Invalid usage.

    Detailed backend outcomes are not encoded as a catalog of exit codes.
    See command help for the meaning of success and failure in each command.

EVIDENCE LIMITS
    A held price is not a guaranteed current market price. The timestamp
    associated with a price in ww prices through the primary option chain is not an
    independently established underlying-quote acquisition time. ww does
    not infer quote age, freshness, trade suitability, or recommendations.

DISCOVERY
    ww --help                  Short command list and example
    ww --man                   This current top-level manual
    ww COMMAND --help | -h     Terse command-specific help
    ww COMMAND --man           Current command-specific behavioral manual
    ww ls quotes --help | -h    Held-quote discovery help
    ww ls quotes --man         Held-quote discovery manual

    Help/man forms are standalone; do not combine them with execution options
    or symbol operands. Execution flags belong to their documented command.

ENVIRONMENT
    WW_BASE_URL   Backend base URL; default http://localhost:3100
    WW_API_TOKEN  Bearer credential for fetch, ls quotes and show, exported or in the
                  private root .ww.env; nonempty exports take precedence; never
                  printed. These require HTTPS outside loopback development.
                  Fetch requires quote.acquire (+ quote.force for --force).
                  ls quotes and show require explicit quote.read independently.

HISTORICAL POSITION OBSERVATIONS
    ww ls position-observations --account pts [--table | --tsv | --jsonl] [--verbose] [--no-color]
    ww positions --account pts --snapshot SNAPSHOT_ID [--verbose | --jsonl | --table] [--no-color]
    Listing is complete retained admitted evidence, not complete brokerage history.
    Full opaque snapshot IDs select exact Account-local observations. No prefixes,
    as-of, automatic predecessor or lifecycle inference. Default show is unchanged.
    Listing defaults to aligned terminal tables and headerless redirected TSV.
    JSONL emits one complete summary per line. Verbose implies table and conflicts
    with TSV/JSONL. Empty catalog emits no machine records and exits 0.
    TSV: accountId, snapshotId, broker, evidenceDate, evidenceDateBasis,
    evidenceDatePrecision, holdingCount, recordedAt, acquisitionStartedAt,
    acquisitionReceivedAt, artifactId, sourceFile, sourceSha256. Null cells empty;
    backslash/tab/CR/LF are escaped. Machine output has no ANSI.
    Display order is not brokerage chronology. Fidelity date precision is one day;
    tastytrade date is UTC receipt day, not broker event time. Selected inventory
    is projected at inspection time: DTE and later same-day Fidelity enrichment
    do not replay historical knowledge. Separate market source provenance remains.
    Reads require existing Account Position-read grants and never acquire.
    Usage exits 2; transport/backend failure exits 1 with stderr diagnostics.
    Original artifact access requires separate authority.

HUMAN POSITION OUTPUT
    Default terminal output and --table show a compact reported-inventory heading
    and aligned records. Custody distinguishes otherwise identical symbols.
    DTE(today) uses the inspection date in New York; ? means unavailable/unknown.
    Signed quantities and adjusted roots are preserved. Past-expiry uncertainty
    remains in the affected record. Evidence dates are observations, not events.
    --verbose includes full snapshot IDs, provenance, acquisition/evaluation clocks,
    additional projected fields and complete qualifications. --jsonl retains the
    complete backend representation. Discovery retains full snapshot IDs in its
    table; its detailed provenance and qualifications are opt-in with --verbose.

PORTFOLIO CAPITAL OBSERVATIONS (candidate)
    ww ls portfolio-capital-observations --account pts [--tsv | --table | --jsonl]
    Pure retained Fidelity read; existing Account metadata/artifact grants. The
    ratified v1 measure is Total Account Value minus aggregate short-option MTM.
    Unique identical reported export-minute pairs are composites, not atomic
    observations. Other Balance rows preserve ? with explicit status. No nearest
    or same-day joining, zero fallback, daily collapse or interpolated values.
    Piped default is TSV: exportMinute, portfolioCapital, status, totalAccountValue,
    shortOptionMtm, balancesArtifactId, optionSummaryArtifactIds. --jsonl preserves
    both hashes, export/quote/receipt dates, minute precision and source rows.
    Example (ordinary presentation; no financial logic in awk):
      ww ls portfolio-capital-observations --account pts | sort -k1,1 |
        awk -v columns=2 -v title='PTS — Portfolio Capital History' -f scripts/unicode-observations.awk
