# Wheelwright — Parking-Lot Continuation

When working with backlog, unresolved project state, or parking-lot material:

- Treat every `docs/parking-lot*.md` file as one logical parking lot.
- Read `docs/parking-lot.md` and every numbered continuation currently present.
- Stable IDs and dispositions are global across the sequence.
- Add new intake to the latest continuation unless reconciling an earlier item's original record.
- File boundaries are physical pagination only; they do not create separate governance, authority, or priority.

The authoritative reading-path and project-memory rules remain in `docs/README.md` and `docs/bootstrap/project-memory-protocol.md`.
