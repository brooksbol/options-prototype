# Idea Intake / Reconciliation Steering

Wheelwright uses one canonical material-idea pipeline:

> **Explore → Intake (`PL-*`) → Reconcile Strategy → Reconcile Architecture → Preserve Why → Decompose → Authorize/Implement**

The governing methodology is:

`docs/foundations/idea-intake-reconciliation.md`

For any material new idea, before proposing roadmap changes or implementation:

1. Read `docs/foundations/idea-intake-reconciliation.md`.
2. Inspect the complete `docs/parking-lot*.md` sequence for an existing concept.
3. Ensure a stable `PL-*` identity exists for genuinely new durable intake.
4. Reconcile against `docs/roadmap.md` and `docs/architecture-roadmap.md`.
5. Preserve material why-state in the journal/checkpoint layer as required.
6. Only then decompose/authorize implementation.

GitHub issues, standalone discovery documents, prompts, and conversation history are supporting artifacts, not substitutes for the canonical parking-lot intake identity.

A Principal statement that an item is "next" establishes sequencing; it does not bypass reconciliation/design gates.
